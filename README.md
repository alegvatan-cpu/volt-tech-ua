# VOLT

Україномовний демонстраційний каталог техніки.

Адреса: https://volt-tech-ua.chalkythyme3.chatgpt.site/volt/

18 товарів, пошук українською та російською, фільтри, порівняння, обране і збереження демо-кошиків у браузері. Ціни та залишки не підтверджені. Справжні продажі не підключені.

Статичні файли: `dist/`. Для локальної перевірки: `python -m http.server 8000 --directory dist`.

SEO: canonical, sitemap.xml, robots.txt, Product, українська локаль. Google самостійно вирішує питання індексації. Для Search Console потрібно підтвердження власником.
